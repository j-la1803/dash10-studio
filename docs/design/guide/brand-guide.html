03Construction, clear space, minimum sizeDASH 10 · BRAND GUIDELINES · V2.1

Construction

Letterforms are custom-drawn artwork. Never retype the logo in a font; always use the supplied SVG files. The rule beneath the wordmark matches its width exactly.

Clear space

Keep clear space on all sides equal to the height of the “D” (x). Nothing enters this zone.

Minimum size

Digital 120 px widePrint 0.75 in wide

Do not reproduce the logo below minimum size. For smaller placements use the monogram (minimum 24 px / 0.25 in).

07Accent systemDASH 10 · BRAND GUIDELINES · V2.1

One accent. Swapped per client.

The brand is monochrome. A single accent supplies small pops of color so a client's palette can slot in without touching the logo. Current accent: Signal Blue #3D7BFF.

Where it appears

  • Website: eyebrow marker, primary button, section numbers, link arrows, code keywords, status meters, focus ring
  • Invoice: rule above payment terms, invoice-number marker, edge of the total-due block
  • Icons: accent set for highlights; monogram accent version
  • Guide and decks: rules, bullets, swatches

How to change it

Edit accent in brand.json and run python3 src/build_all.py. Everything regenerates. For a client copy: --accent "#hex" --out clients/name. The website also accepts ?accent=ff5b2e and has a picker in the footer for live demos.

Rules

Never more than a few percent of any layout. Text on the accent switches automatically to black or white for contrast. Pick an accent that holds at least 3:1 against Jet Black.
